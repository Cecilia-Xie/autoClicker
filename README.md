# AutoClicker (基础优化版)

一个功能完整的 Android 连点器应用，支持多坐标点、延迟点击和可视化反馈。

## 功能特性

### 核心功能
- ✅ **多坐标点支持** - 可同时配置多个点击坐标点，支持动态添加和删除
- ✅ **延迟点击** - 每个坐标点可独立设置延迟时间（0-10000ms）
- ✅ **点击动画** - 执行点击时在对应位置显示红色闪烁指示器，直观显示当前点击位置
- ✅ **悬浮窗控制** - 通过悬浮按钮打开/关闭控制面板
- ✅ **参数可调** - 支持调整点击间隔（50-5000ms）和总时长（0表示无限）
- ✅ **坐标拾取** - 点击屏幕任意位置获取坐标

### 技术实现
- 基于 Android AccessibilityService 实现真正的系统级点击
- 使用 GestureDescription API 模拟触摸事件
- WindowManager 悬浮窗覆盖层
- AlphaAnimation 动画效果

## 当前已实现

### 1. 主界面 (MainActivity)
- 无障碍服务状态检测
- 快捷入口跳转到系统设置

### 2. 悬浮控制面板 (AutoClickAccessibilityService)
- **坐标管理**
  - 显示当前主坐标位置
  - 手动选取坐标功能（点击屏幕获取）
  - 添加新坐标点按钮
  - 坐标点列表展示（每个点显示：序号、坐标、延迟时间）
  - 删除坐标点功能（至少保留1个）

- **延迟设置**
  - 每个坐标点独立的延迟调节（±100ms）
  - 延迟范围：0ms - 10000ms

- **全局设置**
  - 点击间隔调节（±50ms，范围50-5000ms）
  - 总时长调节（±1000ms，0=无限，最大2小时）

- **控制按钮**
  - 开始连点 / 停止连点 / 退出应用

- **视觉反馈**
  - 点击时在目标位置显示60x60dp的红色半透明方块
  - 200ms显示 + 400ms淡出动画，总计600ms后自动消失
  - 同时只显示最新的点击位置指示器

## 使用方法

### 1. 安装与权限
1. 安装 APK 到设备
2. 进入系统 **设置 → 无障碍** 
3. 找到 "Auto Clicker" 服务并开启

### 2. 操作流程
1. 开启无障碍服务后，屏幕左侧会出现悬浮按钮
2. 点击悬浮按钮打开控制面板
3. 配置参数：
   - 点击"手动选取坐标"设置第一个点的位置（或直接使用默认值）
   - 点击"添加坐标点"增加更多点击位置
   - 为每个坐标点设置需要的延迟时间
   - 调整全局间隔和时长
4. 点击"开始连点"启动自动点击
5. 观察红色闪烁指示器确认点击位置
6. 点击"停止连点"或等待超时自动停止

### 3. 多坐标点场景示例
- **游戏连击**：添加多个技能按钮坐标，设置不同延迟实现连招
- **批量操作**：多个确认按钮同时点击，提高效率
- **时序控制**：通过延迟设置实现复杂的点击序列

## 云端构建 APK（GitHub Actions）

1. 将仓库推送到 GitHub。
2. 触发方式：
   - 推送到 `main` 或 `master`
   - 或创建/更新 Pull Request
3. 进入 GitHub 仓库的 **Actions** 页面，打开 `Build Android APK` 工作流。
4. 构建完成后，在该次运行的 **Artifacts** 下载 `app-debug-apk`。

## 本地构建（可选）

如果你本地安装了 Android SDK 和 Gradle 8.7+，可以在根目录执行：

```bash
gradle assembleDebug
```

生成路径：

`app/build/outputs/apk/debug/app-debug.apk`
